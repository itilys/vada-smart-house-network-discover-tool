# VaDa Network Discover 0.1.0

Primera publicación open source de VaDa Network Discover.

Incluye:

- app macOS empaquetada como `VaDa-Network-Discover-macOS.zip`;
- descubrimiento IPv4 de redes locales autorizadas;
- detección de puertos comunes y señales VaDa Solar en el puerto 8090;
- mapa visual, export Mermaid/PNG y persistencia JSON;
- CLI `netdiscover`;
- base inicial para iPad Simulator.

La build macOS está firmada ad-hoc y no notarizada por Apple.
